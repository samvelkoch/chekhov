# Чехов на просвет

Количественное исследование Полного собрания сочинений и писем А. П. Чехова в 30 томах (изд. «Наука», 1974–1983)
с интерактивным отчётом. Сделано по канону [`refs/CANON.md`](refs/CANON.md) (копия из `samvelkoch/brodsky`) — третий
проект серии после «Бродского на просвет» и «Ромена Гари на просвет».

> Готовый отчёт собирается в `docs/prosvet.html` (в `.gitignore`: в нём цитаты). Тексты, извлечённое и посчитанное —
> только локально; в репозитории код, правила и канон.

## Главные вопросы

1. Как менялась проза: длина рассказа и фразы, доля диалога, знаки, подпись и издание (Чехонте → Чехов).
2. Письма (4494): адресаты, места, обращения, подписи и самоименования, брань и купюры издателя.
3. Чехов-врач: советы и практика в письмах, собственная болезнь, врачи в прозе и пьесах.
4. Пьесы: кто говорит, паузы и ремарки.
5. Деньги в письмах: займы и авансы, гонорары, долги, безденежье, суммы.
6. Мир Чехова: люди в письмах, имена героев, места, звери и клички, еда и напитки, сад и дорога, цвета.
7. Мифы и факты — вердикты порогами, записанными до подсчёта (`analysis/rules.py`).

## Пайплайн

| Шаг | Скрипт | Результат (локально) |
|---|---|---|
| 1. EPUB → абзацы с курсивом/полужирным и якорями NCX | `epubflat.py`, `extract.py --qa` | `corpus/` |
| 2. Манифест: роли, годы, подпись в печати, адресаты, даты, места, дубли | `manifest.py --qa` | `texts/` |
| 3. Абзацы по видам, подписи и конверты писем, купюры, леммы pymorphy3 | `analysis/prepare.py --qa` | `analysis/corpus.pkl` |
| 4. Подсчёты по модулям | `analysis/compute.py --qa [модуль …]` | `analysis/stats.json` |
| 5. Отчёт | `analysis/build_report.py` (+ `report.head/body/lib/app/chrome`) | `docs/prosvet.html` |

Явные списки: `analysis/rules.py` (пороги мифов, словари брани и медицины, правило голосов),
`analysis/sig_titles.py` (просмотренные самоименования), `analysis/world_lists.py` (клички, исправления мест и людей), `analysis/med_labels.py` (разметка 171 врачебного абзаца писем,
прочитанного моделью; цитаты проверены как точные подстроки).

## Запуск

```bash
pip install -r requirements.txt
python extract.py --qa && python manifest.py --qa
cd analysis && python prepare.py --qa && python compute.py --qa && python build_report.py
node check_report.js ../docs/prosvet.html
```

## Известные ограничения

Письма в издании 1974–1983 годов напечатаны «без купюр (за исключением мест, неудобных для печати)» — 114 мест
заменены «<…>», поэтому брань в письмах — нижняя оценка. Омонимы не различаются (pymorphy, первый разбор);
словари неполны; год пьесы — год первой публикации, а текст — последняя редакция.
