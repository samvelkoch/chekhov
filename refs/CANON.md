# Канон: количественное исследование творчества одного автора

Этот документ — рабочая инструкция для модели (или человека), которая строит исследование
вида «…на просвет» для другого автора: поэта или прозаика, на любом языке, в оригинале или в переводах.
Он собран по итогам двух проектов:

- **«Бродский на просвет»** — поэт, русский оригинал, один источник на сайте плюс печатное собрание
  (этот репозиторий, `samvelkoch/brodsky`);
- **«Ромен Гари на просвет»** — прозаик, четыре подписи (Гари, Эмиль Ажар, Шатан Богат, Фоско Синибальди),
  корпус в основном из русских переводов десятка переводчиков плюс французские оригиналы, интервью
  и устная речь (`samvelkoch/gary`).

Канон описывает:

1. что спросить у заказчика до начала;
2. как собрать и очистить корпус;
3. какие измерения делать и по каким правилам;
4. как сравнивать голоса (псевдонимы, переводчики) и не обмануться;
5. как проверять себя без ручной разметки;
6. как собрать интерактивный отчёт;
7. какие ошибки уже были и как их не повторить.

Пометки в тексте:

- **[проверено]** — сделано и проверено на Бродском, код в этом репозитории;
- **[проверено на Гари]** — сделано и проверено на Гари, код в `samvelkoch/gary`;
- **[не проверено]** — разумная рекомендация, на практике ещё не опробована.

Код-образец: здесь — `scrape_brodsky.py`, `merge_sib.py`, `build_epub.py`, `analysis/*.py`, `analysis/report4.*`;
в `gary` — `extract.py`, `manifest.py`, `analysis/prepare.py`, `analysis/voices.py`, `analysis/compute.py`,
`analysis/report.*`, `analysis/check_report.js`. Для нового автора код не копируется целиком: берутся модули
и правила, а куски, привязанные к автору (словари, исправления имён, периоды, разрезы текстов), пишутся заново.

## 0. Принципы, которые не обсуждаются

1. **Числа только из данных.** Любое число в отчёте получено запросом к корпусу, а не оценено на глаз.
   Если данные недоступны, так и сказать. Если число — нижняя оценка (словарь мог пропустить слова),
   написать это рядом с числом. Метаданные (годы, переводчики, оригинальные названия) — из внешнего
   источника со ссылкой, а не по памяти; не нашлось — «нет данных».
2. **Никакой ручной разметки и ручной проверки заказчиком.** Проверка — автоматическая: сверка
   с внешними списками, аудит по сырому тексту, выборочный просмотр контекстов самой моделью.
   Если модель заметила ошибку в контекстах, она правит правило, а не данные по одному случаю.
   Исключение — короткий явный список исправлений (склейка написаний одного имени, разрезы
   чужих предисловий и т. п.), который целиком приведён в методике отчёта.
3. **Правило вердикта пишется до подсчёта.** Любое «подтверждается / не подтверждается / отличается»
   выбирается порогом, записанным в код до первого прогона. Если после исправления разметки вердикт
   меняется — это нормально, но текст отчёта должен собираться по результату, а не остаться от прошлого
   прогона. **[проверено на Гари]**
4. **Шкалы не смешиваются.** Меры по разным языкам, по оригиналам и переводам — отдельными
   подкорпусами. Число из одной шкалы нельзя сравнивать с порогом из другой. **[проверено на Гари]**
5. **Читатель не специалист.** Отчёт — развлекательный, но сделанный профессионально.
   Термины заменяются простыми словами, а без которых нельзя (ямб, дольник, рифма, дельта) — объясняются
   на примере из самого автора.
6. **Всё, что можно показать графиком, показывается графиком.** Таблица данных — дополнительно,
   под графиком, свёрнутая.
7. **Тяжёлое — только если необходимо.** Без GPU. Новые пакеты ставятся только тогда, когда без них
   нельзя, и по возможности в отдельное окружение.

Правило проекта: задаётся **один** уточняющий вопрос за раз, только если без ответа нельзя
двигаться. Ниже — список развилок; по каждой есть значение по умолчанию, и спрашивать нужно
только о тех, где умолчание может не подойти.

| Публиковать ли отчёт с цитатами | спросить **до** первого push в публичный репозиторий | авторское право |

## 2. Корпус

### 2.1 Сбор с сайта [проверено]

- Список страниц — из `sitemap.xml`, а не обходом ссылок. Обход проверяется сверкой с картой сайта.
- Каждая страница кешируется на диск (`.html_cache/`, имя — md5 от URL); повторный запуск не ходит в сеть.
- 4 потока, повторы с паузой, журнал пропусков.
- Кодировку определять по байтам: встречается cp1251 внутри utf-8-страниц. Читать байтами,
  декодировать с `errors="replace"`, скрипты и стили удалять до разбора.
- Преобразование HTML → текст для стихов:
  - сырые переводы строк внутри HTML сначала заменить пробелом;
  - потом `<br\b[^>]*>` → `\n` (бывает `<br class="calibre1"/>`), `<p>` → `\n\n`;
  - снять общий отступ.
  Иначе строки стихов склеиваются.
- Для каждого текста сохранить: `url`, `title`, `section` (раздел сайта), `period` (если сайт даёт),
  `source`, `text`. Формат — JSONL, одна запись на текст.

### 2.2 Сбор из файлов заказчика [проверено на Гари]

- Форматы: EPUB (по spine из OPF), EPUB внутри zip, FB2 в zip (`<title-info>` даёт переводчика и `src-lang`),
  docx (`word/document.xml`), rtf (`textutil -convert txt` на macOS), md, txt (субтитры). PDF и mp3 — посчитать
  и назвать, не извлекать, если нет текстового слоя/расшифровки.
- **Классифицировать по содержимому, а не по имени файла.** В папке прошлого проекта заказчика
  `Vie_et_mort_dEmileAjar.md` содержал «Ночь будет спокойной», `Le_judaïsme.md` — сборник статей о Гари,
  `Le_sens_de_ma_vie.md` — системный промпт. Начало текста печатается в журнал для каждого файла.
- **Манифест** — одна строка на файл: что это на самом деле, роль (`own` — художественное, `self` — автор о себе,
  `oral` — устная речь, `twin` — второй перевод, `dup`, `about`, `aux`), язык, подпись (псевдоним),
  год первой публикации, переводчик, примечание. Роли задаются явной таблицей в коде, пересобираемой.
- Отобранные тексты копируются в отдельную папку вне репозитория с понятными именами
  (`texts/ru/1960_Gary_La_Promesse_de_l_aube.txt`) и `texts/manifest.csv`.
- **Годы — по внешней библиографии** (у Гари — fr.wikipedia, статья автора и статья о сборнике рассказов),
  а не по `dc:date` в EPUB: там даты изданий, встречался даже 2026 год. Год написания и год издания
  различаются («Вино мертвецов»: написано 1937, издано 2014) — выбор записать в методике.
- **Переводчик** — из выходных данных в тексте (`Перевод с французского …`, `© …, перевод на русский язык`)
  по **всему** тексту, из FB2-метаданных того же перевода (сверка текста — см. 2.4), иначе из каталогов
  изданий (FantLab и т. п.) с пометкой «по каталогу».

### 2.3 Второй источник и объединение [проверено]

- Печатное собрание (EPUB) разбирается по spine и якорям оглавления (NCX); сноски отделяются.
- Совпадение текстов между источниками — по доле общих 5-словных шинглов:
  больше 0,5 — один и тот же текст.
- Правило выбора версии: берётся источник, где текст полнее; альтернативный перевод оставляется
  отдельно, если он действительно другой.
- **Проверка полноты — по всем языкам.** Однажды подсчёт по кириллице «не нашёл» английских стихов,
  а их было 36. Считать тексты по любому алфавиту.

### 2.4 Дубли, редакции, переводы [проверено; пороги для переводов — на Гари]

- Точный дубль — md5 нормализованного текста.
- Почти-дубль — Jaccard по 5-словным шинглам ≥ 0,9 или вложение одного текста в другой.
  Точный хеш пропустил 11 пар эссе, шинглы нашли.
- Отдельно проверить дубль «полная редакция + фрагмент» (у Бродского — «Набережная неисцелимых»).
- Для переводов по доле общих шинглов меньшего текста **[проверено на Гари]**:
  ≥ 0,9 — тот же перевод; 0,65–0,99 при Jaccard < 0,9 — редакция того же перевода;
  < 0,1 — независимый перевод (пара для «шума перевода», раздел 5). Файлы с одинаковым номером
  в имени (номер книги в библиотеке) почти всегда один перевод — но проверять шинглами.

### 2.5 Классификация [проверено]

Для каждого текста:

- `lang` — по доле латиницы и кириллицы (для латиницы — французский/английский по частым служебным словам);
- `genre` — стихи, если ≥ 85% непустых строк короче 75 знаков и строк ≥ 4; иначе проза.
  Для прозаика — роман / рассказ / интервью / эссе / статья из манифеста; пьесы и письма
  **[не проверено]**;
- `author` / `role` — см. 2.2.

### 2.6 Датировка стихов [проверено]

- Год берётся из **авторской** даты в последних строках текста: короткая строка (≤ 8 слов)
  с годом в допустимом диапазоне жизни.
- Пометы публикатора («Текст по публикации… 1997», «Источник…») исключаются регулярным выражением
  до поиска года. Ошибка на этом месте дала «Акростиху» 1997 год.
- Проверка: сравнить годы с периодами источника. После исправления расхождений стало 6 из 517
  датированных стихов, до исправления было 25.
- Недатированные тексты ставятся в конец своего периода и на графиках рисуются полыми.

### 2.7 Очистка перед подсчётами [проверено; проза — на Гари]

Стихи: убрать редакторские примечания, строки-даты, римские цифры частей, абзацы комментариев внутри
стихотворной записи (строка длиннее 28 слов в стихах), посвящения оставить (в них имена).

Проза из EPUB (fb2 → calibre) **[проверено на Гари]**:

- **Начало:** аннотация, выходные данные, оглавление (список заголовков). Правило: после строки с именем
  автора взять первый абзац длиннее 15 слов; всё до него — служебное.
- **Сноски трёх видов:** отдельный документ spine с `<h1 id="n_12">`; хвост после абзаца `notes` /
  `Примечания`, где ≥ 30% абзацев — голые номера; абзацы вида `[54] текст`. Метки `[8]` в тексте — вычистить.
- **Чужие предисловия и послесловия** (издателя, исследователя) — явным списком разрезов «начать с абзаца …
  / закончить перед …» или «всё до подписи …»; список — в методике. Авторские предисловия оставлять,
  но проверить, какой редакции (у Гари французские «Корни неба» — предисловие 1980 года к тексту 1956-го).
- **Хвост книг издательства:** «Du même auteur», выходные данные электронного издания.
- Проверка: `--qa` печатает начало и конец каждого очищенного текста; все читаются глазами модели.
- Заголовок — абзац до 8 слов без знака в конце; в мерах предложений не участвует.

Автосубтитры (устная речь) **[проверено на Гари]**: убрать `[Musique]`, рекламу перед передачей;
говорящие не разделены — это ограничение, а не мелочь (см. 5.6).

### 2.8 Книги (EPUB) [проверено]

- EPUB3 + NCX вручную через `zipfile`: `mimetype` первым и без сжатия.
- Оглавление в несколько уровней: раздел → период → текст.
- Страницы разделов резервируются в spine до текстов, иначе EPUBCheck даёт NAV-011.
- Проверка: EPUBCheck 5.x без ошибок.

### 2.9 Тематический подкорпус (у Бродского — Венеция) [проверено]

1. Словарь маркеров: леммы и топонимы темы.
2. Каждый кандидат читается в контексте моделью; вердикт записывается в код со строкой-обоснованием.
3. Итог сверяется с внешним перечнем (исследовательская статья, библиография).
   Если внешний перечень находит тексты, которых нет, правило расширяется.
4. Заказчик видит состав и может возразить («всего 13 — не может быть»): проверить,
   не ошибся ли отбор, и показать список с причинами.

## 3. Лингвистическая разметка

### 3.1 Русский [проверено]

- `pymorphy3`, первый разбор, без снятия омонимии. Это даёт систематические ошибки, которые
  нужно знать заранее (раздел 8).
- Служебные части речи (предлоги, союзы, частицы, местоимения) и имена собственные исключаются
  из списков «частых слов». **Местоименные прилагательные** («который», «свой», «этот», «весь», «мой»,
  «такой», «самый», «должный») pymorphy относит к прилагательным — их нужно исключать явным списком,
  иначе они занимают весь топ прилагательных. «Есть» (быть/кушать) исключать из глаголов. **[проверено на Гари]**
- Слоги = число гласных. Для русского это точная мера длины строки.
- Незнакомые словарю имена получают выдуманную лемму («Гари» → «гарь», «Ленни» → «ленний»,
  «Голль»/«Голля» — две леммы). Показывать **самое частое написание**, совпадающее с леммой без учёта
  регистра; склейки — явным списком. **[проверено на Гари]**
- Флаг `word_is_known` у pymorphy: слово с заглавной вне словаря — кандидат в имена; словарное слово
  с заглавной в начале реплики («Короче», «Послушайте») — не имя. **[проверено на Гари]**

### 3.2 Ударения и метр, русский стих [проверено]

- `ruaccent` (модель turbo3.1, словарь, омографы) в **отдельном** окружении: `transformers<5`
  (в 5.x ошибка `token_type_ids`), свой `numpy`. Возобновляемый прогон, результат в JSON.
- Ошибки модели в редких словах и топонимах («Н**о**ренская») переходят в метр и рифму —
  написать это в методике.

### 3.3 Французский [проверено на Гари]

- spaCy `fr_core_news_sm` в **отдельном** окружении (`.venv-fr`), CPU; основной скрипт вызывает его
  подпроцессом через JSON.
- Слова режет свой токенизатор, spaCy получает готовый список (`Doc(nlp.vocab, words=…)`, затем компоненты
  конвейера по очереди) — так леммы выравниваются со словами один к одному.
- Токенизатор: элизии отдельными словами (`l'`, `qu'`, `jusqu'`, `aujourd'hui` целиком), **и с `'`, и с `’`
  (U+2019)**. Обрывки элизий spaCy размечает как NOUN/ADJ/VERB — из списков слов их выкидывать.
- Известные ошибки модели: «Madame» → лемма «monsieur», «Rosa» → NOUN, отдельные кривые леммы («personn»).
  Для стилометрии брать **словоформы**, а не леммы.
- Слог французского стиха — по правилам немого e **[не проверено]**.

### 3.4 Другие языки [не проверено]

| Язык | Морфология | Стих |
|---|---|---|
| Английский | spaCy `en_core_web_sm` | ударения — словарь CMU (`pronouncing`) |
| Смешанный корпус | разметка по языку каждого текста | метрики не смешивать между языками |

Для автора, писавшего на двух языках (Бродский: русский и английский; Гари: французский и английский),
каждый язык — отдельный подкорпус со своим разделом.

### 3.5 Имена [проверено; уточнено на Гари]

Имя — любое из: помета морфологии (`Name/Surn/Patr`, `Geox`; `PROPN` у spaCy); слово с заглавной вне словаря;
слово, которое в корпусе ни разу не встречается со строчной; лемма, которая в ≥ 70% употреблений (и ≥ 2 раз)
пишется с заглавной — последнее ловит омонимы-имена («Кора», «Роза», «Голубчик»).

## 4. Измерения

Каждое измерение ниже описано так: **что**, **как**, **пороги**, **как сказать читателю**.
Пороги — те, что применялись; для другого автора их можно менять, но тогда изменение пишется в методике.

### 4.1 Обзор корпуса [проверено]

Число текстов по жанрам и языкам, слов, разных слов; сколько исключено и почему
(переводы, интервью, чужие тексты, дубли, служебные файлы — числа из манифеста). Тексты по годам,
пики — с биографическими пометками (у Бродского: 1964 ссылка, 1972 эмиграция, 1987 Нобелевская премия;
у Гари — из фактологического профиля заказчика). Для прозаика хронология — столбики «слов в книге»
по году первой публикации, цвет — подпись.

Рост словаря (кривая Хипса): сколько разных слов встретилось, если читать тексты по порядку.

### 4.2 Длина [проверено; проза — на Гари]

- Стихи: слогов в строке — медиана и 25–75% по годам и периодам; распределение по периодам (ридж);
  строк в стихотворении.
- Проза **[проверено на Гари]**: граница фразы — `.`, `!`, `?`, `…`, после которых заглавная, тире или кавычка
  (инициалы дают лишние границы — в методике); типичная фраза — медиана с отрезком 25–75% на точечном
  графике по годам; слов в абзаце повествования; самая длинная фраза с цитатой (у Гари — 429 слов).
- Читателю: «типичная фраза (медиана: половина фраз короче, половина длиннее)».
- Перевод меняет длину: русский перевод на 22–27% короче по словам при том же числе фраз. Длину фразы
  по переводам и по оригиналам не сравнивать.

### 4.3 Размер (стих) [проверено]

- Классический размер (ямб, хорей, дактиль, амфибрахий, анапест, с числом стоп): ≥ 85% строк
  не ставят ударение многосложного слова на слабое место. Пропуск ударения на сильном месте допустим.
- Иначе по промежуткам между ударениями (p1, p2, p3 — доли промежутков в 1, 2, 3 слога):
  - дольник, если p1+p2 ≥ 0,75, min(p1, p2) ≥ 0,15, p3 < 0,12 и промежутков ≥ 5 слогов ≤ 5%;
  - тактовик, если p1+p2+p3 ≥ 0,85 и p3 ≥ 0,12;
  - иначе свободный стих.
- Первая версия (без этого правила) приписала 62% строк 1973–84 годов свободному стиху — ложно.
- Читателю: каждый размер показан на строке самого автора, ударные слоги выделены, под строкой
  схема «та-ТА-та-ТА».

### 4.4 Рифма (стих) [проверено]

- Окончание — от последнего ударного гласного до конца строки, с оглушением конечных согласных
  и редукцией безударных.
- Рифма ищется в окне 4 строк, не дальше соседней строфы.
- Типы: точная (полное совпадение; для открытых мужских — ещё общая согласная перед ударным),
  неточная (отличается одна согласная), созвучие (ударный гласный + последний звук).
- Слова короче 3 букв не рифмуются; составная рифма — два последних слова строки.
- Схемы четверостиший: АБАБ, ААББ, АББА.
- Интерактив «словарь рифм»: слово → с чем автор его рифмовал.
- Ошибки, которые уже были: «ночь — бой», «милая — и». Правило ужесточено; остаточные ошибки
  («ночь — денег») упомянуть в методике.

### 4.5 Строфа, фраза, перенос [проверено]

Строфы по числу строк (тепловая карта по периодам); доля строк, кончающихся предлогом, союзом,
частицей; строк без знака в конце; длина фразы в строках; фраза, переходящая в следующую строфу.

### 4.6 Звук [проверено]

- Аллитерация: ≥ 3 **разных** слова строки на один согласный. Повтор одного слова («Сказал» ×4)
  не считается.
- Сравнение со случайным: те же слова периода перемешиваются и собираются в строки той же длины,
  20 повторов. Вывод зависит от отношения: ≥ 1,15 — «чаще случайного», ≤ 0,9 — «реже»,
  между — «не систематический приём». Не округлять в пользу красивого вывода.

### 4.7 Словарь [проверено]

- Частые существительные, глаголы, прилагательные — топ-20, на 10 000 слов, по подкорпусам отдельно
  (стихи/проза; переводы/оригиналы). Перед показом — глазами проверить, что в топе нет служебных слов (3.1, 3.3).
- Разнообразие: доля разных слов в каждых 500 подряд (MATTR, но в тексте так не называть).
- Закон Ципфа — картинкой.
- «Слова эпох»: log-odds с информативным априором Дирихле (Monroe et al., 2008), слово в периоде
  ≥ 5–10 раз, имена собственные исключены; **слово должно встречаться хотя бы в двух книгах периода**,
  иначе в топе одни персонажи и реалии одной книги; рядом показать число книг. **[проверено на Гари]**
- Словоискатель: индекс начальных форм с частотой по периодам, по подписям, по всем книгам (разреженно:
  `[книга, число, …]` — нужно для подсветки листов в шапке), 1 пример для частых слов. Бюджет: пример режется
  до 170 знаков и даётся словам ≥ 40 употреблений — иначе индекс весит больше мегабайта.
- Карта словаря: 260 частых слов; окно 5 слов → PPMI → SVD (100 измерений) → t-SNE на numpy;
  группы — k-средних. Интерактив: периоды, кнопка «Играть», соседи линиями.

### 4.8 Смысловые поля, эпитеты, сравнения [проверено]

- 16–20 полей × 12–20 слов, поля не пересекаются; частота на 1000 слов по периодам и по подписям;
  клик по полю — его слова и книга, где поле громче всего.
- Вывод «тема растёт/убывает» — сравнением позднего периода со **средним по прежним**, а не первого
  с последним: ряд может скакать (0,3 → 1,1 → 0,3 → 0,6). **[проверено на Гари]**
- Эпитет: согласованное прилагательное перед существительным, устойчивые обороты исключены.
- Сравнения: «как», «словно», «будто», «точно».
- Родительные формулы: существительное + существительное в родительном («часть речи»).

### 4.9 Стиль и его переломы [проверено]

- Для каждого года с ≥ 6 текстами — вектор из 12 мер формы.
- Точки перелома — жадная бинарная сегментация (алгоритму не сообщают биографию).
- Словарное расстояние между годами — Delta Барроуза по 100 частым словам.
- Группы текстов без дат — k-средних; совпадение с периодами — скорректированный индекс Рэнда
  с нулевой моделью (95-й перцентиль перемешанных меток).
- Читателю: «Алгоритм сам искал годы, где стиль меняется резче всего; ему не сообщали дат».
- Для корпуса переводов переломы стиля смешаны с переломами переводчиков — не делать или делать
  только внутри одного переводчика.

### 4.10 Грамматика и пунктуация [проверено]

Существительных на глагол, причастия и деепричастия, местоимения (у каждой мини-диаграммы своя
шкала), знаки на 1000 слов. Для прозы — точечный график «знак на 1000 слов по книгам и годам»
с переключателем знака (`!`, `?`, `…`, тире внутри фразы, `;`, скобки). **[проверено на Гари]**
Сравнивая оригинал и перевод «на 1000 слов», помнить, что в переводе слов меньше: проверять и в штуках.

### 4.11 Мир автора: персонажи, места, вещи [проверено]

**Имена** — см. 3.5. Тип: метки морфологии (`Name/Surn/Patr` — лицо, `Geox` — место), затем соседи.
Имя перед фамилией и отчество после имени не считаются отдельными людьми.
Явный список исправлений (писать в методике): склейка написаний (Харди/Гарди, Уистан → Оден,
Голль/Голля → де Голль), исключения (праздники, названия книг, сам автор; «Франс» у Гари —
это «Эр Франс», «Коллеж де Франс», «Франс-Суар», проверено по контекстам), принудительный тип (Гомер — лицо).

**Пантеон** **[проверено на Гари]**: реальные люди, названные по фамилии хотя бы в 4 книгах. Одиночные
личные имена («Жан», «Мария», «Карл») исключить — это разные персонажи разных книг.

**Сеть персонажей** (поэт; для романиста — внутри книги).

- Связь — оба названы в одной строфе или одном абзаце. Стихи без пустых строк режутся по 12 строк.
- В сети 120 самых упоминаемых по числу текстов, остальные — в поиске.
- Круги имён — спектральная кластеризация + k-средних.
- Раскладка «островами»: круг — остров на кольце, внутри самые частые в центре.

**Рейтинги — по числу текстов, а не упоминаний.** По упоминаниям персонаж одной пьесы
(Публий — 493 упоминания) обгоняет всех.

**Вещи: места без названий, транспорт, еда, напитки, звери, оружие.** Словари лемм по группам.

- Слово с частым другим значением в словарь не входит или получает правило контекста: «виски» — висок
  (у Гари: считать словоформу, если перед ней нет «в/на/по/к/у/его/её»), «паром» — пар, «джин» — только
  со строчной (Джин Сиберг), «змей» (воздушный) ≠ «змея», «чай»-частица, «угол», «камера», «рынок», «буфет».
- Незнакомые pymorphy слова получают выдуманную лемму («граппа» → «грапп»). Ключ словаря
  строится так же, как лемма токена.
- **Аудит по сырому тексту обязателен:** для каждого слова словаря искать основу в сыром тексте
  (`\bоснова[а-яё]{0,3}\b`, основа — слово без последней буквы; слишком короткая основа — «сло» ловит «слово» —
  делает аудит бессмысленным) и сравнивать с засчитанным. Всё, что «по тексту больше», просмотреть глазами:
  у Гари расхождения оказались другими словами («ром» — «роман», «метро» — «метров», «голубь» — «Голубчик»).
- Числа — нижняя оценка, в тексте так и написать. Показывать «редких гостей» с цитатой.
- Вывод о концентрации проверять долей: «слон — почти весь в «Корнях неба»» = 544 из 563 (97%).

### 4.12 Проза: что добавить для прозаика [проверено на Гари, кроме отмеченного]

| Мера | Как | Зачем читателю |
|---|---|---|
| Доля диалога | слова в абзацах-репликах: абзац начинается с тире или кавычки **и короче 120 слов**; длиннее — рассказ героя, это повествование | «сколько в книге разговора» |
| Кто рассказывает | «я, меня, мой…» на 1000 слов по книгам и годам | первое лицо против рассказа со стороны |
| Знаки | см. 4.10 | темперамент |
| Начала и концовки | первая и последняя фраза книги в карточке атласа | как автор начинает и заканчивает |
| Атлас книг | карточка: плитки мер, строение книги (штрих — абзац, цвет — реплика), характерные слова, главные имена и места, темы громче обычного | |
| Длина произведений | распределение, по годам | |
| Сеть персонажей внутри произведения **[не проверено]** | имена в одном абзаце | кто с кем связан |
| Пьесы **[не проверено]** | реплики по персонажам, ремарки | «кто главный по числу слов» |
| Письма **[не проверено]** | адресаты (сеть), частота по годам | отдельный подкорпус |
| Уменьшительные суффиксы **[не проверено]** | -ик, -чик, -очк-, -еньк- | тон |

Ловушка правила диалога: в «Корнях неба» монологи героев идут десятками абзацев, во французском
издании каждый абзац открывается кавычкой, в русском — только первый. Без порога 120 слов доля диалога
вышла 44,8% в оригинале против 28,9% в переводе, «реплика» — 1 566 слов. После порога — 17,6% и 18,5%.
Проверка: сравнить долю диалога в оригинале и переводе одной книги — она должна почти совпадать.

## 5. Голоса: псевдонимы, переводчики, интервью [проверено на Гари]

### 5.1 Мера

Delta Барроуза: z-оценки частот самых частых словоформ, расстояние — среднее модулей разностей.
Читателю: «автор выбирает такие слова не задумываясь — по ним узнают почерк».

### 5.2 Правила, записанные до первого прогона

- Куски текста: 3000 слов (французский, мало книг) или 5000 (русский). Только **повествование**
  (реплики — голоса персонажей), **без имён собственных**, **словоформы**, не леммы.
- Частые слова и средние/σ для z-оценок — на **сбалансированной выборке**: одинаковое число кусков
  от каждой книги (иначе самая толстая книга задаёт словарь).
- Расстояние книга ↔ книга — среднее по всем парам кусков. **Основа сравнения — расстояния между
  разными книгами одного автора**, а не между кусками одной книги (они всегда ближе и занижают порог).
- Вердикт для пары «псевдоним ↔ автор» при базе B (расстояния между книгами автора):
  D > max(B) × 1,10 — «отличается»; D ≤ max(B) — «в пределах разброса»; иначе — «на границе».
- Устойчивость: 100, 200 и 300 частых слов; вердикт ставится, только если одинаков на всех трёх.
- Варианты: без личных и притяжательных местоимений (рассказ от первого лица сближает тексты сам по себе);
  с диалогами. Если вердикт меняется без местоимений — его определяет рассказчик, так и написать.
- Период: псевдоним сравнивать с книгами автора того же периода (Ажар 1974–1979 — с Гари 1970–1980),
  иначе дрейф по годам примут за другой голос.

### 5.3 Переводы: шум, проверка, один переводчик

- **Шум перевода** — расстояние между двумя независимыми переводами одной книги (у Гари 4 пары,
  0,87–1,02). Разница меньше шума выводом не считается.
- **Проверка перевода** на книгах, которые есть на обоих языках: порядок попарных расстояний во французском
  и в русском. Правило: русское сравнение получает вердикт, только если порядок совпадает при 100/200/300.
  У Гари проверка сначала не проходила и прошла после исправления правила диалога; отрыв двух дальних пар —
  0,02, поэтому русский вердикт в отчёте помечен как слабее французского.
- **Один переводчик, разные подписи** — самая чистая русская проверка (у Гари: Н. Мавлевич переводила
  и Гари, и Ажара). Показать, но при одной книге с одной стороны — «мало для вывода».
- **Переводчик или годы**: точечный график пар книг (разница лет × расстояние, цвет — тот же переводчик
  или нет). Считать и показывать n каждой группы: у Гари пар одного переводчика оказалась одна —
  сравнивать переводчиков между собой было нельзя.

### 5.4 Карта и отчёт

Карта кусков — PCA z-оценок (numpy SVD), точка — кусок, подпись группы — у центра; для каждого куска —
«ближайшая чужая книга». Столбики «расстояние до книг автора» с пунктиром базы и +10%, переключатели
варианта и числа слов; текст вердикта — из данных.

### 5.5 Книга-интервью

Если реплики размечены («Франсуа Бонди.», «Ф. Б.», «Р. Г.»), разобрать по говорящим; абзац без метки —
продолжение прежнего. Вопросы и ответы сравнивать **только описательно** (доля слов, длина реплик,
«ты»/«я» на 1000): вопрос и ответ — разные жанры речи, Delta покажет жанр, а не автора. Картинка —
«книга как лента реплик»: ширина реплики — число слов, две дорожки.

### 5.6 Устная речь

Автосубтитры без пунктуации — только частые слова, проекция в пространство письменных книг (те же μ, σ).
Говорящие не разделены: считать **отдельно по каждой передаче** (монолог автора против передачи
с ведущим) и в варианте без местоимений. У Гари вердикт «подтверждается» понизился до «отчасти»: в передаче
с ведущим отрыв ближайшей книги 3,6% при пороге 5%.

## 6. Самопроверка без ручной разметки

1. **Режимы `--qa`, `--audit`, `--ctx` в каждом скрипте:** печатать топ результатов с контекстами,
   пропуски по сырому тексту и контексты выбранных слов. Модель читает вывод и исправляет правила.
2. **Сверка с внешним:** периоды сайта против найденных дат; тематический подкорпус против
   внешнего перечня; число текстов против оглавления собрания; годы и переводчики против библиографии.
3. **Базовая линия для любого «чаще»:** случайная перестановка, нулевая модель, проза того же
   автора как фон, второй перевод как шум.
4. **Проверка вывода фразой:** каждая фраза-вывод собирается из данных шаблоном с условиями
   (вердикт выбирается порогом), а не пишется вручную под ожидаемый ответ. **Перечитать каждую фразу
   против чисел** до публикации: у Гари нашлись «почти во всех книгах» (на деле 28 из 41), «в среднем ближе»
   (по одной паре), «разница исчезает» (1,08 против 1,05), «французских оригинала 15, 17, 17, 17 против 3 чисел
   перевода» (разный состав). **[проверено на Гари]**
5. **Сверка оригинал ↔ перевод как тест разметки:** одна и та же книга на двух языках должна давать
   близкие доли диалога, число фраз, число абзацев-реплик. Расхождение — ошибка правила, а не свойство
   перевода. **[проверено на Гари]**
6. **Ошибки признавать в методике:** что модель ударений путает, что омонимы не различаются,
   что словари неполны, что проверка перевода хрупкая.
7. **Вторая пара глаз:** перед выбором подхода и перед сдачей — ревью (у Гари советник поймал смешение
   шкал и порог «внутри книги»; заказчик — прилагательные и диалог). Замечание проверять данными,
   не соглашаться на слово.

## 7. Отчёт (интерактивный HTML)

### 7.1 Структура [проверено]

Сплошная лента с верхней полосой частей и боковым указателем разделов (вкладки-экраны
заказчику не понравились: «экраны есть, а прокрутка всё равно»).

1. **Шапка**: название, вводный абзац с главным выводом, цифры корпуса, фирменная визуализация
   всего корпуса. Поэт: каждый стих — лист, строка — штрих длиной в слоги. Прозаик **[проверено на Гари]**:
   каждая книга — лист, абзац — штрих длиной в слова, реплики другим цветом, полоска подписи над листом,
   группы по периодам, оригиналам, «о себе»; поиск слова подсвечивает листы; клик — карточка в атласе.
   Шапка на первом экране не должна быть подсвечена словом по умолчанию.
2. **Обзор**: «Главное коротко» (6 цифр), «Мифы и факты» (вердикт порогом), хронология с вехами.
3. **Форма**: для поэта — строка, размер, рифма, строфа, звук, атлас стихотворений;
   для прозаика — фраза, диалог, кто рассказывает, знаки, атлас книг.
4. **Слова**: частые слова, словоискатель, карта словаря, слова эпох, темы, словарь псевдонима.
5. **Голоса** (если есть псевдонимы или переводы): оригиналы, шум перевода, интервью, устная речь.
6. **Мир автора**: пантеон, персонажи, места, полки вещей.
7. **Спецтема** (Венеция).
8. **Оригинал и перевод / второй язык / рекорды / корпус / методика**.

### 7.2 Интерактивы, которые окупились [проверено]

Атлас с карточкой текста; словоискатель; словарь рифм; карта словаря; сеть персонажей с карточкой;
полки вещей с карточкой слова; «Таблица данных» под графиком; у Гари — карта голосов с переключателями
варианта и числа слов, таблица «устная речь → книги».

Каждая карточка открывается сразу в заполненном состоянии.

### 7.3 Оформление [проверено на отзывах заказчика]

- Язык простой. Не писать «лемма», «MATTR», «синтагма», «вещный», «назывной», «keyness».
  Писать «слово во всех формах», «разных слов на каждые 500», «фраза», «сила отличия».
- Тёплая палитра; не холодные сине-фиолетовые. Рукописные шрифты — нет («пошлость»).
- Серия отчётов — одно оформление: стили, шрифты, палитра, ядро графиков переносятся из предыдущего
  отчёта (`report*.head.html`, ядро JS), пишется заново только содержание.
- Категориальная палитра проходит валидатор (`dataviz`) для обеих тем. Цвет несёт группу (у Гари — подпись),
  текст — всегда цветом текста.
- Обе темы через токены `:root`; тёмная — свои значения, а не инверсия.
- Шрифты — Google Fonts, подключение асинхронное.
- **Русский язык в шаблонах** **[проверено на Гари]**: согласование числительных (`plural(n,'текст','текста','текстов')`
  для каждого числа в тексте); названия книг в косвенном падеже не склонять, а писать «в книге «Чародеи»»;
  переведённые книги — русскими названиями (таблица соответствий), оригинал — в карточке.
- **Вёрстка** **[проверено на Гари]**: подписи точек — с проверкой пересечений и правого края; длинные
  названия в списках обрезать с «…»; в узкой карточке — HTML-список «книга — полоска — число», а не
  график с осью; сетка карточек без одинокого элемента в последнем ряду (2×2 вместо 3+1, 9 рекордов вместо 8);
  шкала точечного графика — по данным, без пустого запаса до «круглых» 100.

### 7.4 Техника [проверено]

- Один HTML-файл, без библиотек: SVG и canvas вручную.
- Данные — в `<script type="application/json">`, подставляются сборщиком (`build_report.py`).
  Экранировать `</` в JSON.
- **Отрисовка порциями:** очередь `chart(fn, box)` → `pump` по 12 мс. Кеш CSS-токенов, перерисовка по смене
  темы и ширины.
- Шаблон собирается из частей (`head` + `body` + данные + ядро + отчёт + навигация); `.gitignore`
  должен пропускать эти части (у Гари `*.html` сначала не пропустил `report.body.html`).
- Размер: ~2,5–3 МБ для 50–600 текстов — нормально.

### 7.5 Проверка перед публикацией [проверено]

1. Скрипт-сверка (`check_report.js`): синтаксис каждого `<script>` через `new Function`, все `id`,
   к которым обращается JS, есть в разметке.
2. Headless Chrome: ошибки JS — вставить перед страницей перехват `error` и `console.error`, через 8 с
   дописать в DOM `ERRS:[…]`, число отрисованных SVG и `scrollWidth`; снять `--dump-dom`. Системные ошибки
   Chrome на macOS (дисплей, сертификаты) — не про страницу.
3. Снимки: десктоп светлая и тёмная, телефон 500 px. В headless тема задаётся атрибутом `data-theme`
   во временной копии: флаг `preferredColorScheme` игнорируется. Длинную страницу снимать окном
   1400 × 30000 и резать на куски по 2400 (PIL); окно 16000 обрезает страницу.
4. Каждый кусок — глазами модели: наложения подписей, падежи, пустые шкалы, одинокие карточки.
5. Публикация как артефакт; исправления — повторная публикация того же файла (ссылка сохраняется).
6. Перед push в **публичный** репозиторий — спросить заказчика про HTML с цитатами (варианты: оставить,
   убрать из репозитория, сделать репозиторий приватным).
